# pairwise-video-stabilize

手持拍摄的湖面视频，开了防抖后画面像果冻，转场处还会突然放大：防抖只读陀螺仪角速度，没有和帧时间戳对齐；滚动快门按固定行时间校正，不同曝光行读出方向反了；裁剪比例固定，抖动大时画面不够裁；地平线锁定用加速度计，快速平移时误判重力方向；防抖延迟没补偿，直播画面比声音慢；可变帧率素材的帧间隔不均，平滑窗口按帧数算导致抖动；镜头畸变在防抖前没校正，边缘 warp 拉不直；场景切换时沿用上一段运动轨迹，转场出现漂移；10bit/HLG 素材在 8bit 缓冲里防抖，色带明显；多相机切换时陀螺仪偏置没重估，画面缓慢倾斜；防抖后的画面没有重新计算安全区，字幕被裁；GPU 和 CPU 各算一套 warp，预览和导出不一致；防抖缓存按视频 ID，换镜头后仍用旧轨迹。media/video_stabilize.py 是核心，tests/test_video_stabilize.py 15个红。要修的是：时间戳对齐；滚动快门；动态裁剪；地平线；延迟补偿；VFR 窗口；畸变顺序；切点重置；高位深；多相机偏置；安全区；预览导出一致；缓存隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
